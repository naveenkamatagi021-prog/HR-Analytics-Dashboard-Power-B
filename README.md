# 👥 HR Analytics Dashboard | Power BI

## 📌 Project Overview

An interactive **HR Analytics Dashboard** developed using **Microsoft Power BI** to analyze employee workforce data and understand attrition patterns across different employee characteristics.

## 🎯 Objectives

* Analyze employee distribution and workforce characteristics.
* Understand employee attrition patterns.
* Identify attrition trends across age, education, salary, and job roles.
* Analyze workforce performance using interactive visualizations.
* Provide data-driven insights for HR decision-making.

## 🔄 Data Analytics Workflow

**Data Extraction → Data Cleaning → Data Preprocessing → Data Transformation → Data Analysis → Data Visualization**

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Cleaning
* Data Preprocessing
* Data Visualization

## 🧹 Data Cleaning & Preprocessing

* Extracted employee data from the source dataset.
* Checked missing and inconsistent values.
* Removed duplicate records where required.
* Corrected data types.
* Standardized categorical fields.
* Transformed the dataset using Power Query.
* Created calculated measures using DAX.

## 📊 Key HR Metrics

The dashboard analyzes:

* Employee Count
* Attrition Count
* Attrition Rate
* Average Age
* Average Salary
* Years at Company

## 📈 Dashboard Analysis

* Attrition by Education
* Attrition by Age Group
* Attrition by Salary Range
* Attrition by Job Role
* Employee distribution
* Workforce and attrition trends

## 🎛️ Interactive Dashboard

Interactive charts, slicers, filters, and KPIs allow users to explore employee and attrition patterns dynamically.

## 💡 Business Insights

The dashboard helps HR teams identify employee groups with higher attrition and understand how factors such as age, education, salary, and job role influence workforce retention.
